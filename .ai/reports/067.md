## What moved where
- **Navigation**: the 11 tabs are now 5 sections (`nav_tabs.php`): الرئيسية, الطلبات, المستخدمون, الاشتراكات, الإعدادات. Right sidebar on desktop (sticky); fixed bottom bar below 768px. The الإعدادات section has a sub-tab strip (in `admin.php`): السياسات، الأسعار وطرق الدفع (publicPortal)، الإصدارات، الإشعارات والبث (push + broadcast shown together)، الملاحظات، المشرفون، توليد التراخيص. `switchTab(oldId)` still works for every old id, so existing callers and the saved-hash restore keep working. The last tab is remembered in `localStorage` (`mosarib_admin_tab`); the first visit opens الرئيسية. The pending-requests badge (`badgeReqCount`) now sits on the الطلبات nav item.
- **الرئيسية**: 4 clickable KPI cards (`widget_overview.php`): طلبات تنتظر التفعيل → requests (pending), مشتركون فعّالون → users (ACTIVE), تنتهي خلال 7 أيام → subscriptions (soon), نشطون اليوم → users (TODAY). Computed in `updateStats()` from the lists already loaded. The old 8-card stats grid is kept (all ids intact) inside a «كل المؤشرات» collapsible, and the analytics charts follow below. The home block only shows in the Home section.
- **المستخدمون**: 7 columns instead of 10: user, device, one status chip (تجريبي / مشترك حتى date / منتهٍ / ملغى / محظور), remaining free operations (with bar, «مقفل» at 0, «غير محدود» for subscribers), last seen (relative, full date on hover), and one ⋮ menu with all previous actions plus 065's تفعيل / تمديد / إلغاء التفعيل. Search kept; filter chips now: الكل، مشتركون، تجريبي، منتهٍ، محظور، نشطون اليوم، تجاوزوا الحد، النسخ معطّل، المحذوفون. Price per hour and "backup locked" moved into the device cell as small notes. Phones show each row as a card. Sticky header, empty state, loading skeleton.
- **الاشتراكات (new)**: `widget_subscriptions.php` + `renderSubscriptionsList()` / `setSubsFilter()`. One row per device from `subscriptionByDevice` (newest licence): subscriber, device code, plan, expiry with «بعد N يوم / منذ N يوم», status chip («ينتهي خلال N يوم» ≤ 7 days, منتهٍ, ملغى, فعّال), filters الكل / ينتهي قريباً / منتهٍ / ملغى plus search, and a «تمديد» action that reuses `openExtendModal` (065). The old «اشتراكات تنتهي قريباً» card (reminder push + WhatsApp) was moved here, below the list, unchanged.
- **Polish**: spacing scale 4/8/12/16/24, 12 and 16px radii, new AA text tokens (`--success-text`, `--danger-text`, `--accent-text`, `--cyan-text`, chip backgrounds) defined for dark and light, light `--text-muted` darkened for contrast, focus-visible outlines, reduced-motion respected. Toast is lifted above the phone bottom bar.

## Behaviour notes
- No Firebase read/write, auth, CSRF or proxy code changed. The ⋮ menu calls the same functions as before.
- Chip counts: «تجريبي» now means a never-subscribed user only; expired or revoked users are counted under «منتهٍ» (before, they were counted as trial).
- `setUserFilter` now clears only the user chips (it used to clear every pill on the page).

- The `admin-auth.js` tab-restore list is unchanged, so a `#subs` URL hash is restored by `admin-core.js` only (works, since both run at load).
- «الإعدادات» nav button opens السياسات (it does not remember the last sub-tab on a click, only on reload).
