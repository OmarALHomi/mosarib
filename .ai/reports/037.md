## Round 2 Review Items
1. **Page 1 balance cell:** In `ComprehensiveReportMath.page1BalanceCell`, farmers show `receivableBalance` (red if > 0, green otherwise), owners with `payableBalance > 0` show «له [المبلغ]» in green with `isDebt = false`, and neither `billed - paid` nor `balance` is used.
2. **Page 1 debt totals:** Page 1 grand total row and the "ديون العملاء" KPI card reverted back to `totals.totalOutstandingDebt` (sum of `receivableBalance`), removing `totalCustomerDebt` so owners with net payables are never counted as customer debt.
3. **Owner payables card:** The "مستحقات أصحاب الآبار" KPI card now directly uses `totals.ownerPayable`.
4. **Owners table irrigation debt:** The "دين السقي عليه" column in the well owners table reverted back to `row.receivableBalance`, keeping `payableBalance` exclusively under "متبقي له علينا".
5. **Pure accounting test:** `ComprehensiveReportAccountingTest` now builds real farmer and well-owner rows using `calculateCustomerBalance` and asserts that the owner cell displays «له 102,853» in green, the farmer cell equals his receivable debt, and total customer debt excludes the owner.
6. **Adaptive keep-together:** Expanded keep-together pagination logic in `PdfReportGenerator.kt` to allow the last 1–2 remaining rows to squeeze onto the current page down to `pageHeight - 48f`, updating the upfront `ownerPagesCount` simulation in exact lockstep.
7. **Selective Drive list refresh:** In `DriveAutoBackupSection`, previous WorkInfo state history is tracked to only trigger `onRefreshDriveBackups()` when `lastBackupTime` changes or a job transitions from RUNNING/ENQUEUED to SUCCEEDED, preventing repeated reloads on static SUCCEEDED history.
8. **Owners table purchase cell clipping:** The "شراء: مسجل / محتسب / هدر" column in the well owners table is now rendered using `drawClippedCell(canvas, hoursText, 295f, 425f, curY + 14f, paint)` so long 3-part BiDi durations auto-shrink without overflowing the 130 pt cell.
