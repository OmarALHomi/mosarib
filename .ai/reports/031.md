# Report 031: About page, the mandatory subscription screen, update and announcement notices

## Summary
- **Part 0 (Critical Force Update Logic):** Corrected the force update rule in `AppUpdateManager` so `isForceUpdate` flag alone never locks users who are already on or above `minRequiredVersionCode`. Added offline fallback caching in SharedPreferences to prevent bypassing force updates by turning off Wi-Fi/mobile data, and added unit tests for `shouldForceUpdate(currentCode, minCode, flag)` covering all 5 required test cases.
- **Part A (About Page):** Replaced hard-coded version text with dynamic `BuildConfig.VERSION_NAME` and `BuildConfig.VERSION_CODE` ("الإصدار 1.4.0 (بناء 5)") and dynamic copyright year. Reorganized `AboutScreen` into the 5 structured sections: App card with license chip and device code copy button, 4 one-line feature rows (omitting voice input since Task 030 is not merged), Developer card, Links (including new `mosarib.tubbasoft.com`), and Footer.
- **Part B (Mandatory Subscription Screen):** Added back press interception via `BackHandler` inside the `ModalBottomSheet` content calling `finishAffinity()` and added a visible text button "خروج من التطبيق" at the bottom of `LicenseDialog` when `isMandatory = true`. Preserved strict modal retention so the sheet cannot be dismissed into the app.
- **Part C (Update and Announcement Notices):** Redesigned `ForceUpdateScreen` and `BroadcastAnnouncementDialog` to use Mosarib design tokens (adaptive to light and dark themes) and removed all emojis from titles and buttons. Implemented same-day dismissal for announcements when clicking "لاحقاً". Reviewed and polished app-level notices in `MainScreen.kt`, including adding a gentle license expiry notice for subscribers with 5 or fewer days remaining.
- **Part D (Date Line in Text Messages):** Replaced fixed 📅 emoji (which rendered as "17" on most keyboards) with dynamic day keycap digits (`digit + "️⃣"`), Arabic weekday, and Western digits date (`dd/MM/yyyy`) using unified `MessageFormatHelper.dateLine(millis, label)`. Added unit tests for days 1, 9, 10, 17, 31 and all weekday names.

## Decisions and doubts
- For the date line in text messages, the task spec included the handwritten example `"5️⃣ الأربعاء · 05/11/2026"`. On the real calendar, November 5, 2026 falls on a Thursday (الخميس), whereas November 4, 2026 is Wednesday. The implementation uses deterministic calendar calculations mapping `Calendar.DAY_OF_WEEK` to exact Arabic day names so that any date is 100% calendar-accurate across all platforms and time zones. Unit tests explicitly test Wednesday (e.g. 2026-08-05), Thursday (2026-11-05), Tuesday (2026-10-27), days 1, 9, 10, 17, 31, and all 7 Arabic weekday names.
