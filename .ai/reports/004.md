## Key Changes Detail
1. **Swipe Navigation**: Added `userScrollEnabled = false` to `HorizontalPager` in `MainScreen.kt`.
2. **Tab Naming**: Unified names across `AppTab` enum and `MosaribNavBar` (`mosaribNavItems`): "التقارير", "العملاء", "الرئيسية", "العمليات", "الإعدادات". Top bar reads `currentTab.title` directly.
3. **Accessibility**:
   - Navigation bar items use `selectable(selected = isSelected, role = Role.Tab, onClick = ...)`.
   - Floating circle indicator uses `clearAndSetSemantics { }` to prevent duplicate announcements in screen readers.
   - Free operations counter includes `semantics { contentDescription = "العمليات المجانية المتبقية: $remaining" ; role = Role.Button }`.
4. **Top Bar Clean-up**:
   - Removed `LivingThemeToggleButton` from non-home top bar.
   - Feedback star icon button is now restricted to `currentTab == AppTab.SETTINGS`.
   - Free operations counter touch target expanded to >= 48dp via `Modifier.minimumInteractiveComponentSize()`, and text typography mapped to `MaterialTheme.typography.labelSmall`.
