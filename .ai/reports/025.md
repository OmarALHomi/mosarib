# Report 025: Voice Reading (TTS) & WhatsApp Voice Statements

## Summary
Implemented the offline voice reading feature using Android's native TextToSpeech engine with lazy initialization, strict offline Arabic voice discovery and binding (prioritizing Google Speech Services over engines lacking Arabic or network-only voices), and comprehensive error propagation. Created `MosaribSpeaker` singleton, `SpeechPronunciation` pronunciation normalizer with domain diacritics, `SpeechTextBuilder` for natural pause-form Arabic phrasing without tanween, `SpeakButton` and card menu items across ledger and voucher screens, fast AAC M4A voice statement compression via `MediaCodec` + `MediaMuxer` with WhatsApp sharing in `VoiceStatementExporter`, and an expanded "القراءة الصوتية" settings section with speech rate control, active voice picker bottom sheet, pronunciation test sample, and engine status. All speech functionality is gated behind the subscriber license with lock badges and informative upgrade prompts for free users.

## Round 4 Implementation Details

### 1. WhatsApp Voice Statement Text Caption
- **Caption Builder (`SpeechTextBuilder.buildVoiceStatementCaption`):**
  - Formats statement caption text passed to `Intent.EXTRA_TEXT` alongside `Intent.EXTRA_STREAM` in `VoiceStatementExporter.shareVoiceFile`:
    ```text
    🔊 كشف حساب صوتي: {customer name}
    الرصيد: عليه 13,163 ر.ي (ثلاثة عشر ألفاً ومائة وثلاثة وستون ريالاً)   ← or له / مسدد
    آخر {N} عمليات · بتاريخ {dd/MM/yyyy}
    من: {distributor name} {distributor phone if set}

    ---
    تطبيق المسرّب | م. عمر الحومي
    mosarib.tubbasoft.com
    wa.me/967773712030
    ```
  - Exact written words formatted using `Formatters.amountToArabicWords` with formal padding ("فقط", "لا غير") stripped.
  - Queries `distributor_phone` from settings and appends it to distributor name when set.
- **Shared Footer:**
  - In `core/util/FileSharingHelper.kt`, updated `MESSAGE_FOOTER` to add line `mosarib.tubbasoft.com` below "تطبيق المسرّب | م. عمر الحومي" while retaining `wa.me/967773712030`.
  - Reused `FileSharingHelper.attachMessageFooter(body)` so all messages across the app share the exact unified footer.
- **Unit Tests (`SpeechTextBuilderTest.kt`):**
  - `testVoiceStatementCaptionOwed`: verifies "عليه" direction, formatted amount, exact words in parentheses, operations line, date `dd/MM/yyyy`, distributor phone, and footer.
  - `testVoiceStatementCaptionCreditWithoutPhone`: verifies "له" direction and omitted phone suffix when distributor phone is blank.
  - `testVoiceStatementCaptionSettled`: verifies "مسدد" format without amount or direction keywords.

### 2. Pronunciation & Vocabulary Corrections
- **"عليك" reading:**
  - Added dictionary vocalizations to prevent feminine "عليكِ":
    - عليك → عَلَيْكَ
    - لك → لَكَ
    - عليكم → عَلَيْكُم
  - Includes full prefix mappings (و / ب / ل / ال / فـ) automatically generated in `SpeechPronunciation.DICTIONARY`.
  - Verified with unit tests in `SpeechTextBuilderTest.testDictionaryWordsAndPrefixesPronunciation`.
- **Compound numbers with "مِئة":**
  - Ensured kasra on "مِئة" everywhere in `SAMPLE_PRONUNCIATION_TEXT` ("مِئة وخمسة وعشرون ألف", "سَبْع مِئة", "ثلاثة آلاف وخمس مِئة").
  - Ensured `SpeechPronunciation.forSpeech` maps all occurrences of "مئة" and "مائة" to "مِئة".
- **2,000,000 Pronunciation:**
  - Updated `SpeechTextBuilder.amountToSpeechWords` from "مليونان" to "مليونين" (2,000,000 → "مليونين ريال").
  - Updated unit tests and sample pronunciation text.

### 3. Generic Voice Alias Filter
- In `MosaribSpeaker.getInstalledOfflineArabicVoices` and `testCandidateEngine`:
  - When more than one offline Arabic voice is installed, the generic alias `"ar-language"` is filtered out, leaving only distinct voices (e.g. `ar-xa-x-ard-local`, `ar-xa-x-arc-local`, etc.).
