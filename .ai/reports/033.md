## Decisions and doubts
- **Local Dev Router**: `web_dashboard/dev-router.php` is strictly for local PHP built-in web server routing (`php -S localhost:8000 dev-router.php`) and **must not be deployed to production**.
- **Admin Portal Settings Extension**: Because `widget_public_portal.php` is not in the allowed files list, settings controls for `stats_wells`, `stats_vouchers`, and dynamic `testimonials` management (add/remove rows) were dynamically injected into `#portalSettingsForm` via `assets/js/admin-core.js`, maintaining clean architectural boundaries.
- **Flock-Guarded Analytics & Throttling**: Visitor counter deduplication and rate limiting files (`portal_analytics.json`, `login_attempts.json`, `subscription_requests.json`) utilize atomic file locking (`flock(LOCK_EX)`) to prevent concurrency corruption, while crawler/bot user-agents are filtered out.
- **Stored XSS Elimination**: All interpolated user inputs in the admin dashboard (feedbacks, user subscriptions, broadcast notifications, modal logs) are safely escaped via `escapeHtml()`. Public submission payloads are truncated to 80 chars server-side with strict phone format validation.
- **Purged Personal Details**: Hardcoded personal recipient details (name, bank account, and phone number) were completely removed from `index.php`; when `payment_methods.json` is empty, visitors are instructed to contact support directly via WhatsApp.
- **Dynamic APK Fallback**: Release version and file size are dynamically calculated in MB; if no release record exists, version and size labels are cleanly omitted rather than showing outdated dummy data.
- **Bidi and Design Fixes**: Latin technical names (`Google Drive`, `PDF`, `APK`, `Excel`) are wrapped in `<bdi>` tags, "حساب دقيق بالدقيقة" replaces old wording, heading sizes use responsive `clamp()`, and mobile containers apply a clean 16px gutter.
