# Report 015: Coloured operation cards (restored and unified) and customer cards with تفقيط

## Summary
Restored and standardized type-coloured operation cards using a unified `OperationCard` component across all operation types (Receipt, Expense, Discount, Session, Purchase), with consistent 1.4dp accent borders, start-edge accent bars, type badges, large signed amounts, and amount in words (تفقيط) always shown under every amount. Customer cards in `CustomerCardItem` were completely aligned with the same visual language, coloured dynamically by financial status (`debt`, `credit`, `settled`) with amount in words and clear status chips.

### Round 1 Fixes & Polish:
1. **Name and badge layout in Header:** Resolved root cause where unconstrained end columns squeezed title columns. Restructured header into 2 clean lines:
   - **Line 1:** Name / Title takes `weight(1f)` with ellipsis (farmer's name is completely visible without wrapping or truncation), amount is intrinsic bold at the end.
   - **Line 2:** Badges take intrinsic width (`softWrap = false`, never shrink or break), followed by amount in words taking `weight(1f)` end-aligned.
2. **Kebab moved to Meta Row:** Removed kebab from the header and placed it in the meta & actions row, eliminating header crowding.
3. **Session Chips Row:** Single non-wrapping row containing duration in short form (`Formatters.formatDurationCompact`, e.g. "2س 30د"), rate ("4,000/س"), and status chip pushed to the end ("مسدد", "غير مسدد", or "باقي Y" without repeating paid amount).
4. **Meta & Actions Row:** Meta string on start (`weight(1f)`), followed by compact 32dp tonal button ("سداد" when debt > 0), expand chevron (40dp target when linked payments exist), and kebab (40dp target).
5. **CustomerCardItem Alignment & Quick Actions:**
   - Header with avatar (44dp) outside text column, Line 1 name (`weight(1f)`) + balance, Line 2 chips (no shrink) + tafqeet (`weight(1f)` end-aligned).
   - Bottom row contains: phone number (`weight(1f)`), WhatsApp statement button (`Icons.AutoMirrored.Filled.Send`, 40dp), PDF statement button (`Icons.Default.PictureAsPdf`, 40dp), Call button (`Icons.Default.Call`, 40dp), and kebab menu (`Icons.Default.MoreVert`, 40dp).
   - Tafqeet in customer card is darker and bolder (`FontWeight.SemiBold`, 100% `stateColor`).
6. **Clean Tafqeet on Cards:** Stripped "فقط" and "لا غير" from card display across all cards, rendering clean concise wording (e.g. "عشرة آلاف ر.ي" instead of "فقط عشرة آلاف ر.ي لا غير").
7. **Darker and Compact Statement (البيان):**
   - Font size reduced slightly (`12.5.sp`) with bold/dark contrast (`FontWeight.SemiBold`, `onSurface`) for improved readability.
   - Expense cards now consistently display their statement box (`voucher.notes`) without suppression.
8. **Reference Deduplication:** Cleaned prefix formatting so `#REC-144109-144` is built cleanly without duplicating `#REC-REC-...`.

### 3. Approximate Tafqeet on Cards
- Added `Formatters.amountToArabicWordsApprox(amount: Double, currency: String = "ر.ي"): String`.
- `abs(amount) < 100`: exact words without "فقط" / "لا غير".
- `abs(amount) >= 100`: rounded to nearest 100 (half-up):
  - If rounded value equals amount: exact words without "تقريباً" (e.g. `12500` → `"اثنا عشر ألفاً وخمسمائة ر.ي"`).
  - If rounded value differs: rounded words followed by `" تقريباً"` (e.g. `13163` → `"ثلاثة عشر ألفاً ومائتا ر.ي تقريباً"`, `150` → `"مائتا ر.ي تقريباً"`).
  - Negative amounts use absolute value.
- Unit tests verified: 50, 12500, 13163, 13140, 150, 99.5.
- Applied in `OperationCard` and `CustomerCardItem`.

### 4. Avatar Initials
- Updated initials extraction in `CustomerCardItem`: first letter of first word + first letter of last word, stripping leading "ال" from the last word.
- Example: `"أحمد بن حسين العولقي"` → `"أع"`. One-word names return one letter (e.g. `"أحمد"` → `"أ"`).
- Unit tests verified in `ExampleUnitTest.kt`.
