# Report 003: Design-system foundation (semantic colours, shapes, spacing, type floor)

## Summary
Built the design system foundations for Mosarib by adding extended semantic color tokens (`MosaribExtendedColors`) with light and dark mode mappings, standardized `MosaribShapes`, a unified `Spacing` scale, and raised the type floor of `labelSmall` from 10sp to 11sp. Provided extended tokens via `LocalMosaribExtendedColors` and `MaterialTheme.mosarib` inside `MosaribTheme`.
