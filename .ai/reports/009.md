## Bottom Bar Structure & Status Bar Inset Handling
- **Status & Navigation Bar Insets:** Configured via `SideEffect` in `MainScreen.kt` inside `MosaribTheme(darkTheme = darkTheme)`. When light theme is active, `isAppearanceLightStatusBars = true` and `isAppearanceLightNavigationBars = true` (dark icons); when dark theme is active, both are `false` (light icons). Dynamically updates whenever the user toggles theme.
- **Material 3 Navigation Bar:** Implemented using `NavigationBar` (container color `surface`, tonal elevation `3.dp`) and `NavigationBarItem`.
- **Canvas-drawn Icons:** Maintained `AnalyticsChartIcon`, `CustomersBadgeIcon`, `HomeDropHouseIcon`, `OperationsClipboardIcon`, and `SettingsMaintenanceIcon` with proper dynamic tints (`primary` when selected, `onSurfaceVariant` when unselected).
- **Labels:** `alwaysShowLabel = true`, `labelMedium` (12sp), single line (`maxLines = 1, softWrap = false`).
- **Indicator Styling:** `MaterialTheme.colorScheme.primaryContainer` in light mode, `primary` at 24% alpha in dark mode.
- **Icon Selection Animation:** Added spring bounce scale animation (1.0 → 1.12 → 1.0) on tab selection using `animateFloatAsState` with `Spring.DampingRatioMediumBouncy` and `Spring.StiffnessMediumLow`.
- **Code Clean-up:** Removed `DynamicCrestedBarShape`, floating indicator circle, and unused multi-line label code.
