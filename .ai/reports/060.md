# Report 060: empty forms, validation like a web form, summary words, small fixes

## Items
1. **New forms open empty** (new = no edit, no voice prefill; both unchanged).
   - Session form: price empty (placeholder «مثلاً <default price>»), من/إلى show «اختر الوقت», duration empty,
     summary card shows «—» until time and price exist. Customer's saved price still fills when picked
     (`priceTextFor`). Typing a duration with no time set derives من = now - duration (or = إلى - duration
     if only إلى was chosen) and إلى accordingly.
   - Purchase form: same for من/إلى/duration; «المستحق له / المتبقي بذمتك» show «—» until ready.
     Price was already empty; placeholder is fixed «مثلاً 5,000» (this sheet has no default-price param).
2. **Save always enabled + validation.** Order logic is the pure `firstMissingField(...)`
   (core/ui/FormValidation.kt, unit-tested). Session: customer, من, إلى, duration range, price, waste ≤ duration.
   Purchase: owner, من, إلى, duration range, price, waste. Voucher: customer (قبض only), المبلغ
   (amount, or discount on a قبض as before). On the first missing field: BringIntoViewRequester scroll, red
   border and «هذا الحقل مطلوب», focus (text field focus + keyboard, customer picker opens, time box opens the
   time picker). Error clears as soon as the field is filled. Range errors reuse the same mechanism
   (duration > 10 days scrolls to the existing red card; waste opens the extras and scrolls to its red message).
   The 048 confirmation sheet, send dialog and edit/voice flows are untouched; it only opens after validation.
   `pricePerHour` in the session form no longer silently falls back to the default price (empty is now an error).
3. **Summary tiles** (VouchersScreen): مقبوض, صرف, شراء (sum of `WellOwnerPurchaseMath.payableAmount` over
   `PurchaseOp` in the period), متبقي (`ledgerTotalsFor` owedToUs, caption «عند الناس الآن»);
   small line «عليك للآخرين: Y» (owedByUs) and the ساعات السقي line. «الباقي في الصندوق» removed.
4. **ساعات السقي** now `hoursAsNumbers`: «1,570 ساعة و5 دقائق».
5. **«+ عميل جديد» in the purchase owner picker**: new `onCreateCustomer` param; opens
   `AddEditCustomerBottomSheet`, creates the customer with `isWellOwner = true` and selects it once it appears
   in the owners list. Wired in VouchersScreen (add sheet), HomeScreen, CustomerDetailScreen.
