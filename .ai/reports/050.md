# Report 050 - Subscription screen clearer

File changed: `app/src/main/java/com/example/core/license/LicenseDialog.kt` only.

## New section order (the «الاشتراكات والتفعيل» sheet, shown to unregistered users)
1. Header (unchanged), then a one-sentence status box:
   - trial running: «أنت في الفترة التجريبية: بقي لك N عملية مجانية» (N = limit - `LicenseManager.getCumulativeOperations`).
   - trial ended (`isMandatory`): «انتهت الفترة التجريبية. بياناتك محفوظة، ويمكنك التصفح، لكن إضافة العمليات تحتاج اشتراكاً»; `mandatoryReason`, when passed, appears under it in small text.
2. Internet status line (unchanged).
3. Step cards with a numbered circle:
   - ١ اختر الباقة: monthly/yearly buttons. «جاري التحميل...» and the «باقة 30/365 يوماً» fallbacks are now «—»; when prices are not configured a row shows a message and an «إعادة المحاولة» button (calls the existing `refreshConfig()`).
   - ٢ ادفع: transfer-method dropdown, the collapsible accounts card (account details + copy), transfer number field (all moved as-is).
   - ٣ أرسل الطلب: name, phone, big «إرسال الطلب عبر واتساب» (`openWhatsApp()`), plus a small secondary «أو أرسل الطلب إلى الإدارة من داخل التطبيق» (`submitOnlineSubscriptionRequest()`), success message.
   - ٤ أدخل رمز التفعيل: key field, error text, «تفعيل التطبيق الآن» (`submitActivation()`).
4. «مسجل مسبقاً ولديك اشتراك؟» Google restore card (unchanged).
5. Collapsed «تفاصيل إضافية»: region field, device model line, device code with tap-to-copy (replaces the old Device Code card's copy button).
6. Collapsed «مميزات الاشتراك» (features card, was always open).
7. Exit button when mandatory (unchanged).

## Removed
- Old long explanation paragraph and the "active registration summary" card inside the sheet, and the isRegistered / yearly / monthly button branches of the old device-code card. The sheet is only composed when `!isRegistered`, so these branches were unreachable. The registered renewal Dialog (the other branch of `LicenseDialog`) is untouched.

## Skipped
- Status sentences for "subscription active until <date>" / "expired at <date>": the sheet only shows for non-registered users, so they never apply there; the registered dialog already shows days remaining / expired and was left alone to keep the change to the sheet.
- No cached last price: `FirebaseLicenseService.getSubscriptionPricing` already returns what it has; when blank we show «—» plus retry.

## Logic
No network call, validation, activation path, or Firebase interaction changed (same functions, same arguments).
