# Report 054 - Backup page simplified

Files changed: `SettingsBackupScreen.kt`, `SettingsBackupDialogs.kt` only.

## New blocks (top to bottom)
1. **حالة النسخ الاحتياطي**: two lines (phone / Drive) with relative date (اليوم / أمس / قبل N يوم); green check when today, amber when older than 7 days. Big button «انسخ الآن» = `onCreateBackup()` (existing file-save launcher) plus `DriveBackupScheduler.enqueueImmediateBackup` when a Google account is linked.
2. **النسخ التلقائي**: switch (existing `onAutoBackupEnabledChange`; when an account is linked it also sets the Drive frequency to OFF / DAILY and reschedules). When on: chips يومي (DAILY) / أسبوعي (WEEKLY), then «ربط بحساب Google» or «مرتبط بـ email» + «فصل الحساب». Under «إعدادات أخرى»: Wi-Fi only switch and last Drive errors.
3. **استعادة**: «استعادة نسخة» opens `BackupListDialog` (new, in Dialogs file) listing phone (manual + safety checkpoint) and Drive copies together, newest first, with source icon, date, size. Tap sets the existing restore state, so the existing confirmation dialogs are used.
4. **متقدم** (collapsed): استيراد ملف, مشاركة ملف النسخة (`onShareNewBackup`), تنظيف النسخ القديمة (existing confirm), فحص العمليات المكررة, حذف نسخ (same list dialog in manage mode: per-row share for local files and delete -> existing delete confirmations).

## Where old actions live
- نسخة جديدة -> انسخ الآن; استيراد / مشاركة / فحص المكرر -> متقدم.
- Per-file local share, local/auto/Drive delete -> متقدم > حذف نسخ.
- Drive sign-out -> account row. Frequency / Wi-Fi / errors -> sections 2.
- Local/Drive restore -> استعادة نسخة.
