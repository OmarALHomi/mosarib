File changed: `app/src/main/java/com/example/core/license/LicenseDialog.kt` (non-registered branch only; the `isRegistered` renewal dialog and every network call, validation and activation function are untouched).

## Card (step 0, shown first)
Centred `Dialog`, 90% width, 24dp rounded surface, 12dp shadow, max height 80% of screen. Lock (trial ended) or key icon in a tinted circle; title «انتهت الفترة التجريبية» / «اشترك في المسرّب»; line «بياناتك محفوظة ...» or «بقي لك N عملية مجانية» (plus `mandatoryReason` in small text if given); buttons «طلب اشتراك» (primary), «إغلاق» (secondary, `onDismiss`), link «لديّ رمز تفعيل» (jumps to step 4), and «خروج من التطبيق» (only when `isMandatory`, existing `finishAffinity`).

## Stepper (same dialog)
Top: ١—٢—٣—٤ progress (filled up to current) + step title. Body scrolls; bottom «السابق» / «التالي» (step 4: «تفعيل», enabled only when the key format is valid, calls existing `submitActivation`). Internet status row stays at top of the body; errors from `errorMessage` show under steps 3 and 4.
1. الباقة: monthly / yearly selectors with prices, «—» + «إعادة المحاولة» when pricing is missing (unchanged content).
2. الدفع: payment-method menu, expandable list of accounts (copy button), optional receipt number.
3. بياناتك: name, phone, big WhatsApp button, small in-app request button, success message. Below, collapsed «تفاصيل إضافية» containing the Google restore card, region, device model and device code, and the features list.
4. رمز التفعيل: line «ستصلك الرسالة بالرمز بعد تأكيد الدفع», the code field. The old in-step activate button was removed; the bottom «تفعيل» replaces it.

## Back / close
`DialogProperties(dismissOnBackPress = false)` and a `BackHandler` inside the dialog: steps 2–4 go to the previous step, step 1 goes to the card, the card calls `onDismiss()`. «إغلاق» and tapping outside call `onDismiss()` always, also when `isMandatory`. The app is never closed by back.
