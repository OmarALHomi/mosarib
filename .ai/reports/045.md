# Report 045 - Voucher form: قبض/صرف, pick-only customer, simple mode

## Files changed
- features/vouchers/VouchersScreen.kt (AddVoucherBottomSheet + two call sites)
- features/home/HomeScreen.kt (wiring only)
- core/ui/CustomerPickerField.kt (`onAddNew` is now nullable; the «+ عميل جديد» item is hidden when null)

## Items
1. Type toggle labels now «قبض» / «صرف»; colours and behaviour unchanged.
2. Receipt customer: `MosaribAutoCompleteTextField` replaced by `CustomerPickerField`. `onSelect` sets `selectedCustomerId` and clears `amountStr`, so the existing `LaunchedEffect(selectedCustomerId, type)` still selects all unsettled sessions. «+ عميل جديد» opens `AddEditCustomerBottomSheet` (same as the session form); the new customer is selected after saving. New param `onCreateCustomer: (suspend (Customer) -> Long)? = null`, wired from VouchersScreen (both calls, via `sessionsViewModel?`) and HomeScreen. `LockedVoucherCustomer` is untouched. Voice prefill still works; an unmatched spoken name shows a «لم أتعرّف على» hint.
3. Expense beneficiary menu: «+ عميل جديد» added as the first item (above «مصروف عام»); it selects the new customer as beneficiary.
4. Simple mode: type, customer/beneficiary, amount and save stay visible. Discount, payment method, notes and frequent-description chips are in a collapsed «خيارات إضافية» card (auto-open if discount/notes filled, payment method not «نقداً», or a voice command is present). Full mode is unchanged. The voucher form has no date field, so there was none to move.

## Differences / not done
- Call sites that don't pass `onCreateCustomer` (QuickAddVoucherSheet in CustomersScreenDialogs, CustomerDetailScreen) don't show «+ عميل جديد». The former is outside the allowed files, the latter has a locked customer.
- Removed the now-unused MosaribAutoCompleteTextField imports. `custDropdownExpanded` was removed.
- GuideRegistry not touched; the `voucher_customer`, `voucher_payment_method`, `voucher_notes` and `voucher_discount` targets still exist, but those inside the collapsed card are not visible in simple mode until it is opened.

- testDebugUnitTest: passed (exit 0); the test task recompiled the code after the import cleanup.
