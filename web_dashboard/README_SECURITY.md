# 🛡️ المعايير الأمنية المطبقة في لوحة إدارة مُسَرِّب (Royal Enterprise Security)

تم بناء نظام حماية متكامل وعسكري يمنع أي شخص من الدخول أو التحكم بالتطبيق بدون مصادقة رسمية مشفرة:

---

### 1️⃣ تسجيل الدخول الإلزامي (Authentication):
- **لا يمكن لأي مستخدم فتح اللوحة أو رؤية أي معلومة أو إرسال إشعار** دون إدخال بريد إلكتروني وكلمة مرور صحيحة ومسجلة في النظام.
- **الحساب الافتراضي للمسؤول الرئيسي:**
  - **البريد الإلكتروني:** `admin@mosarib.com`
  - **كلمة المرور:** `Admin@2026!`
  - *(يمكنك تغييرها أو إضافة مسؤولين جدد من تبويب: "🛡️ مسؤولو النظام والأمان").*

---

### 2️⃣ التشفير عالي الأمان (Password Hashing):
- كلمات المرور لا تُحفظ كنص عادي أبداً، بل تُشفر باستخدام أحدث خوارزميات التشفير العالمية المقاومة للاختراق **Argon2id / Bcrypt**.

---

### 3️⃣ مكافحة التخمين والهجمات العنيفة (Rate Limiting & Brute-Force Protection):
- إذا حاول أي شخص تخمين كلمة المرور وأخطأ **5 مرات متتالية**، يقوم السيرفر بحظر عنوان IP الخاص به فوراً لمدة **15 دقيقة**.

---

### 4️⃣ حماية الجلسات ورموز CSRF (Cross-Site Request Forgery):
- حماية كافة الطلبات بـ `csrf_token` عشوائي 64-bit يمنع أي موقع خبيث من تنفيذ عمليات بالنيابة عنك.
- ملفات الجلسات محمية بخواص `HttpOnly` و `SameSite=Strict` لمنع سرقة الكوكيز عبر ثغرات XSS.

---

### 5️⃣ حماية المجلدات والبيانات (.htaccess Protection):
- مجلد `data/` الذي يحتوي على بيانات المسؤولين محظور تماماً من المتصفح `Deny from all`، بحيث إذا حاول أي شخص فتحه مباشرة من الرابط يظهر له فوراً خطأ **403 Forbidden**.
