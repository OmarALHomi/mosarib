# 🏗️ الخطة المعمارية الشاملة (النسخة المعدّلة v2)
## منظومة الري والمحاصيل الزراعية — تطبيق واحد، 4 أدوار، تطبيق أدمن منفصل

---

## 1. إعادة تسمية التطبيق

التطبيق حالياً اسمه **«المُسَرِّب»** — وهو اسم يخدم دوراً واحداً فقط. بما أننا نوسّعه ليخدم 4 أطراف مختلفة، نحتاج اسماً شاملاً يعبّر عن المنظومة كلها:

| المقترح | المعنى | لماذا؟ |
|---|---|---|
| **جِربة** | الجربة = قطعة الأرض الزراعية (مصطلح يمني شائع) | اسم قصير ومألوف ويشمل كل الأطراف حول المزرعة |
| **محصول** | كل ما يُنتج من الأرض | عام وشامل لكل المحاصيل |
| **مِسقاة** | مكان السقي والري | يربط بالسقي لكن يتسع للبيع والشراء |
| **غَيْل** | مجرى الماء الزراعي | يمني أصيل ومعروف |

> [!NOTE]
> **اقتراحي الأقوى: «جِربة»** — لأنه:
> - مألوف لكل مزارع ومسرب ودلال ومجبري في اليمن.
> - قصير وسهل النطق والتذكر (4 أحرف).
> - لا يحصر التطبيق في دور واحد.
> - يصلح كعلامة تجارية: «تطبيق جِربة — منظومتك الزراعية الشاملة».
>
> **لكن القرار النهائي لك** — إذا تفضل اسماً آخر أو تريد الإبقاء على «المسرب» أخبرني.

## 2. الأدوار الأربعة — ماذا يفعل كل دور بالضبط؟

### القاعدة الذهبية: كل دور عنده **دفاتره ومعاملاته الخاصة**

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    ما يشترك فيه كل الأدوار (مجاناً)                      │
├──────────────────────────────────────────────────────────────────────────┤
│  ✅ دفاتر حسابات خاصة (ديون، مصروفات، حسابات عامة)                    │
│  ✅ تقييد معاملات (له/عليه) مع أي طرف                                  │
│  ✅ إشعارات عبر واتساب مباشر                                           │
│  ✅ نسخ احتياطي محلي                                                    │
└──────────────────────────────────────────────────────────────────────────┘
```

### تفصيل كل دور:

#### 💧 المسرب (مقدم خدمة الري)
| الميزة | وصفها |
|---|---|
| تسجيل العملاء (المزارعين) | يضيف اسم المزارع والمزرعة ويولّد له كود ربط |
| تسجيل جلسات السقي | ساعة البداية والنهاية + السعر + المقبوض |
| سندات القبض والصرف | نظام FIFO للسداد التدريجي |
| توليد كود ربط | كود 5 أرقام يُرسله للمزارع ليرى حسابه |
| تقارير مالية + PDF | كشوفات حسابية وتقارير الأداء |
| مضخات ومصادر الماء | إدارة الآبار والمضخات |
| **دفاتره الخاصة** | مصروفات الديزل، صيانة المضخة، ديون شخصية |

#### 🌾 المزارع (صاحب الأرض)
| الميزة | وصفها |
|---|---|
| كشف حساب المسرب | يرى سقيات المسرب ورصيده المتبقي (للقراءة فقط) |
| الربط بعدة مسربين | يدخل كود الربط من كل مسرب يسقي له |
| طلب دلال لبيع الثمرة | يرسل طلب تسويق لدلال في العزلة |
| **دفاتره الخاصة** | مصروفات المزرعة: رش، سماد، عمال، بذور |
| ⭐ ميزات التوثيق المدفوعة | تسجيل بيع وشراء محاصيل + حساب أرباح المزرعة + طباعة كشوفات |

#### 🤝 الدلال (الوسيط/السمسار)
| الميزة | وصفها |
|---|---|
| نشر عروض الثمار | ينشر مزارع مثمرة في سوق العزلة |
| حماية هاتف المزارع | يخفي رقم المزارع لحماية سعايته |
| تسجيل عقود الصلح | يوثق الاتفاق بين البائع والمشتري |
| سجل السعايات | يتتبع عمولاته (مستلمة/باقية) |
| **دفاتره الخاصة** | حسابات مع مزارعين ومجابرة، ديون شخصية |

#### 📦 المشتري / المجبري (مشتري المحاصيل)
| الميزة | وصفها |
|---|---|
| تصفح عروض الثمار | يرى كل العروض المتاحة في العزلة |
| طلب معاينة | يتواصل مع الدلال للنزول للمزرعة |
| كشف مشترياته | يرى عقود الصلح المسجلة باسمه |
| تسديد الأقساط | يتتبع المتبقي عليه لكل صلح |
| **دفاتره الخاصة** | حسابات شراء محاصيل، مصروفات نقل، ديون |
| ⭐ ميزات مدفوعة | تسجيل مصروفات لكل مزرعة اشتراها + حساب أرباح البيع بالتجزئة + طباعة كشوفات |

### كيف يضيف المستخدم دوراً ثانياً لاحقاً؟

**من الإعدادات → «أدواري»:**

المستخدم يرى قائمة بالأدوار الأربعة ويستطيع تفعيل أي دور إضافي **يدوياً بنفسه**:

```
┌──────────────────────────────────────────────────────────────┐
│  ⚙️ أدواري في التطبيق                                       │
│                                                              │
│  ✅ 💧 مسرب (دوري الأساسي)                                  │
│                                                              │
│  ☐ 🌾 مزارع                                                │
│     اضغط لتفعيل: ستظهر لك شاشة المزارع                    │
│     وستتمكن من إدخال كود الربط من أي مسرب                  │
│                                                              │
│  ☐ 🤝 دلال                                                 │
│     اضغط لتفعيل: ستظهر لك شاشات نشر العروض                │
│     والصلح (يحتاج اشتراك بعد الفترة التجريبية)             │
│                                                              │
│  ☐ 📦 مشتري/مجبري                                          │
│     اضغط لتفعيل: ستظهر لك شاشة تصفح العروض                │
│     وسجل مشترياتك                                           │
│                                                              │
│  💡 تفعيل دور إضافي = تظهر لك شاشات                       │
│     وأزرار ذلك الدور بجانب دورك الأساسي.                   │
│     بياناتك في كل دور مستقلة تماماً.                        │
└──────────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **توضيح مهم — لا يوجد تفعيل تلقائي للأدوار:**
> - كل مستخدم **يختار بنفسه** أي أدوار يريد تفعيلها.
> - تفعيل دور = تظهر له شاشات وأزرار ذلك الدور في التطبيق.
> - **لا يتحول** شخص من دور لآخر بدون إرادته.
> - مثال: شخص اسمه **أبو أحمد** — هو مسرب يسقي الناس، وفي نفس الوقت عنده مزرعة يسقيها مسرب آخر اسمه **أبو صالح**:
>   1. أبو أحمد يسجل في التطبيق كـ **مسرب** (دوره الأساسي).
>   2. يذهب للإعدادات ← يُفعّل دور **مزارع** إضافياً.
>   3. الآن عنده شاشتان: شاشة المسرب (يسجل سقي لعملائه) + شاشة المزارع (يدخل كود الربط من أبو صالح ليرى حسابه معه).
>   4. كل شاشة مستقلة — لا تخلط البيانات.

### من يمكنه أن يكون مشترياً (مجبرياً)؟

- **أي شخص** يستطيع تفعيل دور المشتري، بغض النظر عن دوره الأساسي.
- عملياً في الواقع:
  - **المزارع** نفسه قد يشتري ثمرة مزرعة مزارع آخر (يصبح مزارع + مشتري).
  - **المسرب** قد يشتري محصولاً (يصبح مسرب + مشتري).
  - **الدلال** لا يكون مشترياً عادة (يتوسط فقط)، لكن تقنياً مسموح.
- **القيد الوحيد:** لا يستطيع شخص أن يكون **البائع والمشتري في نفس عقد الصلح** (يمنعه التطبيق).

### ما هو مجاني وما هو مدفوع لكل دور:

#### 💧 المسرب:
| مجاني (أول 200 عملية) | مدفوع (بعد الحد المجاني) |
|---|---|
| ✅ تسجيل عملاء وسقيات | ✅ عمليات لا محدودة |
| ✅ سندات قبض وصرف | ✅ مزامنة سحابية مع المزارع |
| ✅ تقارير أساسية | ✅ نسخ احتياطي Google Drive |
| ✅ دفاتر خاصة | ✅ تقارير PDF متقدمة |

#### 🌾 المزارع:
| مجاني دائماً | مدفوع (توثيق الحساب) |
|---|---|
| ✅ كشف حساب مسرب واحد (قراءة) | ✅ ربط بأكثر من مسرب |
| ✅ دفاتر مصروفات بسيطة | ✅ تسجيل بيع وشراء محاصيل |
| ✅ طلب دلال لتسويق الثمرة | ✅ حساب أرباح المزرعة (إيرادات − مصروفات) |
| ✅ رؤية عقود الصلح الخاصة به | ✅ طباعة كشوفات PDF |
| | ✅ إرفاق صور المزرعة |

#### 🤝 الدلال:
| مجاني (فترة تجريبية) | مدفوع (بعد الحد المجاني) |
|---|---|
| ✅ 5 عروض ثمار | ✅ عروض لا محدودة |
| ✅ 3 عقود صلح | ✅ عقود صلح لا محدودة |
| ✅ دفاتر خاصة | ✅ تثبيت العروض في مقدمة السوق |
| ✅ مشاركة واتساب | ✅ سجل سعايات متقدم + PDF |

#### 📦 المشتري/المجبري:
| مجاني دائماً | مدفوع (اشتراك) |
|---|---|
| ✅ تصفح كل عروض العزلة | ✅ تسجيل مصروفات لكل مزرعة اشتراها |
| ✅ طلب معاينة من الدلال | ✅ حساب أرباح البيع بالتجزئة |
| ✅ رؤية عقود الصلح باسمه | ✅ طباعة كشوفات PDF |
| ✅ دفاتر خاصة بسيطة | ✅ تسديد أقساط مع إشعار تلقائي للبائع |
| | ✅ تتبع مخزون المحاصيل المشتراة |

### لماذا HTML وليس تطبيق أندرويد منفصل؟

| HTML (المقترح) | تطبيق أندرويد منفصل |
|---|---|
| ✅ ملف واحد فقط — لا تثبيت | ❌ تحتاج مشروع ثانٍ كامل |
| ✅ يعمل على أي جهاز (جوال/كمبيوتر) | ❌ أندرويد فقط |

| ✅ `localStorage` يحفظ السجلات | ❌ يحتاج قاعدة بيانات |
| ✅ Firebase JS SDK لإدارة Firestore | ❌ برمجة مكررة |

> [!TIP]
> **الخلاصة:** صفحة HTML واحدة محسّنة بتصميم premium تعمل على جوالك أو لابتوبك، فيها كل ما تحتاجه لإدارة المنظومة. إذا أردت لاحقاً تطبيقاً أصلياً يمكن بناؤه، لكن الآن HTML أسرع وأكثر أماناً.

## 6. مشاركة البيانات بين الأدوار (الآلية التفصيلية)

### القناة 1: المسرب ← المزارع (كشف حساب السقي)

```
خطوة 1: المسرب يضيف عميلاً في تطبيقه
         ↓
         التطبيق يولّد تلقائياً كود ربط: 58204
         ↓
خطوة 2: المسرب يرسل الكود للمزارع (واتساب أو شفهياً أو QR)
         ↓
خطوة 3: المزارع يفتح تطبيقه ← يذهب لشاشة «حسابات السقي»
         ← يضغط «+ ربط حساب مسرب جديد»
         ← يدخل الكود 58204
         ↓
خطوة 4: التطبيق يتحقق من الكود في Firestore
         ← يجده ← يربط المزارع بالمسرب
         ↓
خطوة 5: من الآن فصاعداً:
         - كل سقية يسجلها المسرب تُكتب في Room + Firestore
         - المزارع يقرأ من Firestore ← يرى الرصيد محدّثاً
         - المزارع لا يستطيع التعديل ← قراءة فقط
```

### القناة 2: المزارع → الدلال (طلب تسويق)

```
خطوة 1: المزارع يضغط «🔔 طلب دلال لتسويق مزرعتي»
         ← يختار نوع المحصول + وصف + صورة (اختياري)
         ← يختار دلالاً محدداً أو «إرسال لكل دلالي العزلة»
         ↓
خطوة 2: الطلب يُكتب في Firestore: marketing_requests/{id}
         ↓
خطوة 3: الدلال يصله إشعار FCM: «المزارع فلان يطلب منك تسويق مزرعته»
         ↓
خطوة 4: الدلال يفتح الطلب ← يقبله ← ينشر العرض في سوق الثمار
```

### القناة 3: الدلال → الجميع (عروض الثمار)

```
خطوة 1: الدلال ينشر عرضاً في التطبيق:
         - نوع المحصول (قات/عنب/رمان/...)
         - الوصف والحالة والصورة
         - خيار «إخفاء هاتف المزارع»: ✅ مفعل افتراضياً
         ↓
خطوة 2: العرض يُكتب في Firestore: listings/{id}
         ↓
خطوة 3: كل مستخدم في نفس العزلة يرى العرض في تبويب «سوق الثمار»
         ↓
خطوة 4: المشتري يضغط «تواصل مع الدلال»
         ← يفتح واتساب الدلال برسالة جاهزة
         ← أو يُرسل إشعار FCM للدلال
```

### القناة 4: الدلال → المزارع + المشتري (عقد الصلح)

```
خطوة 1: بعد المعاينة الميدانية، الدلال يسجل الصلح:
         - البائع: اسم المزارع (مسجل أو غير مسجل)
         - المشتري: اسم المجبري (مسجل أو غير مسجل)
         - المبلغ + العربون + المتبقي + السعاية
         ↓
خطوة 2: الصلح يُكتب في Firestore: deals/{id}
         ↓
خطوة 3: التطبيق يُحدّث حالة العرض ← «تم البيع ✅»
         ↓
خطوة 4: إذا المزارع مسجل ← يرى الصلح في «مبيعاتي»
         إذا المشتري مسجل ← يرى الصلح في «مشترياتي وديوني»
         إذا غير مسجلين ← يرسل الدلال سند الصلح بالواتساب
         ↓
خطوة 5: تسديد الأقساط:
         - الدلال (أو المزارع) يسجل دفعة جديدة من المتبقي
         - يتحدث الرصيد عند كل الأطراف المسجلة
```

## 8. العواقب والحالات الحرجة

| الحالة | الحل |
|---|---|
| **مزارع غير مسجل في التطبيق** | الدلال يكتب اسمه يدوياً + يرسل سند الصلح واتساب |
| **انقطاع الإنترنت أثناء التسجيل** | كل شيء يُحفظ محلياً أولاً ← يُزامن عند عودة النت |
| **مزارع مرتبط بمسربين** | يدخل كود ربط لكل مسرب ← يرى بطاقة منفصلة لكل واحد |
| **انتهاء اشتراك المسرب** | البيانات تبقى ← يُمنع من عمليات جديدة فقط ← المزارع يرى آخر رصيد |
| **شخص بدورين مدفوعين** | يحتاج مفتاحين مستقلين (بادئات مختلفة) ← كل مفتاح له عداده |
| **دلالان يدّعيان صلح نفس المزرعة** | أول صلح يحوّل العرض لـ «تم البيع» ← الثاني لا يجده |
| **مشتري يريد التلاعب بالصلح** | المشتري يرى فقط ← الدلال هو الوحيد الذي يسجل ويعدل |
| **المسرب حذف عميلاً عنده سجل عند المزارع** | السجل يبقى في Firestore ← المزارع يرى «حساب مغلق» |
