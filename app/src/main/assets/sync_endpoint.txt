# قناة المزامنة (ح٢٢) — قالب فارغ عن قصد.
#
# اكتب سطرًا واحدًا: العنوان الأساسي للخادم، مثل:
#     https://sync.example.com
# ويُبنى عليه مسار العقد الثابت: /api/v1/changes
#
# لماذا في أصل بنائي (asset) لا في إعداد يحرّره المستخدم؟
# لأن تغيير العنوان يعني أن تُرسل دفاتر الناس إلى خادم آخر. لو صار العنوان قابلًا للتحرير من
# الشاشة، لكفى من يمسك الجهاز دقيقةً واحدة ليحوّل بيانات العائلة إلى خادمه. فالعنوان يُغيَّر
# ببناء جديد، مثل قناة الإصدار (ح٢٠) بالضبط.
#
# شروط تُفحص عند القراءة ويرفض المخالف:
#   • https فقط (والتطبيق يمنع النصّ المكشوف أصلًا: usesCleartextTraffic="false").
#   • لا سطر اعتباري ثانٍ: أول سطر غير فارغ وغير بدئه # هو العنوان.
#   • لا رمز ولا سرّ في هذا الملفّ: رمز الجهاز يُخزَّن على الجهاز ويتولّد عشوائيًّا.
#
# قالبه فارغ في المستودع: غيابه ⇒ لا قناة، والتطبيق يعمل محليًّا كاملًا (وهذا هو الأصل).
