# مفتاح التصاريح العام (ح١٣) — قالب يملؤه المالك قبل التوزيع.
#
# الطريقة:
#   1. افتح tools/license_keygen.html في متصفح بلا إنترنت، وولّد زوج مفاتيح P-256 مرة واحدة.
#      المفتاح الخاص يبقى عندك (ملف على جهازك أو مدير أسرار) ولا يدخل المستودع ولا التطبيق أبدًا.
#   2. انسخ نصّ المفتاح العام (X.509/SPKI بصيغة PEM) والصقه في هذا الملف بدل هذه الأسطر.
#   3. أعِد البناء. لوحة الأدمن (tools/key_generator.html) توقّع التصاريح بالمفتاح الخاص،
#      والتطبيق يتحقق منها بهذا المفتاح العام وحده.
#
# حتى تُلصق المفتاح الحقيقي تبقى التصاريح الموقّعة مرفوضة برسالة صريحة
# («هذه النسخة لا تحمل مفتاح التصاريح العام») — وهو أصدق من قبول كل شيء بلا تحقق.
#
# مثال الشكل (لا تعمل به، ولا تستنسخه):
# -----BEGIN PUBLIC KEY-----
# MFkwEwYHKoZIzj0CAQYIKoZIzj0DAQcDQgAE...  (سطر base64 واحد أو عدّة أسطر)
# -----END PUBLIC KEY-----
