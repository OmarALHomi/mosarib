# هذا قالب بلا مفتاح عن قصد:
#   ١. المالك يولّد زوجًا جديدًا خاصًّا بقناة التحديث (لا يُعيد استعمال مفتاح التصاريح):
#        openssl ecparam -name prime256v1 -genkey -noout -out release-key.pem
#        openssl ec -in release-key.pem -pubout -out release-public.pem
#   ٢. يلصق محتوى release-public.pem (سطر PEM أو base64 مجرّد) مكان هذا الملفّ.
#   ٣. يحتفظ بالملفّ الخاصّ خارج الجهاز والمستودع، ويوقّع به ملفّ الإصدار:
#        node tools/release_sign.mjs --key release-key.pem --payload "..."
#
# وإن بقي الملفّ قالبًا، فقناة التحديث تقول بصراحة «مفتاح التحقق غير مُسلَّم» ولا تعرض إصدارًا
